**What changed, and who asked for it**

- **Beat 1 now ends in a ransom note.** Day six: admin identities carry passwords the attacker set, service accounts too, backups deleted, disks encrypted, every application down, nobody can log in to see why. Then the demand. One line answers the "never me" reflex: real incidents have run exactly this sequence. *(Mick)*
- **Beat 1 closes on a gap analysis.** What happened, and the control that would have stopped it, six rows, no company named, no score kept. It ends by asking the room which of these they actually have. *(Chris, with Rick's controls in the rows)*
- **Why the agent could write at all.** The fabric optimizer was provisioned with write rights because that is its job, and whatever it loads inherits them. The dwell step says the attacker skips the routes because a drift scanner would revert them, and spends day one on identities and backups instead. *(Rick)*
- **The managed-registry step is named as ahead of most companies**, not behind. *(Mick)*
- **The sandbox escape is rewritten.** The second stage is an agent, not a script. The sandbox has no internet and no internal route; the agent probes the boundary, finds a weakness nobody knew about, and gets out. Hugging Face is named. "A shift" became "four to eight hours across three teams". *(Mick, with Rick's line that an agent has no ethics)*
- **Every agent carries a declared persona**: who it acts for, what it may want, its autonomy envelope. Runtime drift is measured against it. *(Peter)*
- **The reference architectures are in.** The unified map and the WG1 control plane in Beat 3, the WG2 drawing at the start of Beat 4, the WG3 drawing at the start of Beat 5, each with the planning phase, the execution phase and the gate named. Loop step names and gate names now follow the drawings: Verify Gate for the NOC, Decide Gate for the SOC. *(Peter, Nick)*
- **"Agentic control plane" is named** on the band, the panel and each beat's first mention. The sandbox is described once: it runs the artifact for real, with writes intercepted before any device. *(Baird)*
- **A card before the vendor challenge** lists the other threat scenarios the same controls address: indirect prompt injection, agent misuse of legitimate rights, over-broad write access. *(Baird)*
- **The proof points** now draw the line between an employee's personal agent, which is easy to interrupt, and a company's agentic workflow with its own identity, rights and data, which is what the plane exists to govern. *(Baird, Mick)*
- **The close** is now the message to the room: the vendor demos play in the networking areas and the Collaborative Center, go watch, vote Best in Show per lane in Whova. The member logos are on the title and the finale, and you are credited by name with your company's mark. Tell me if you would rather not be.

The narration was cut to fit ten minutes. The numbers are still illustrative.
