One Path Shown, Fifty-Nine Catalogued

Source: AOMC Threat & Risk Scenario Catalog· ingested 2026-09-23· owner: ONUG Collaborative· status: not WG1-ratified
Fifty-nine scenarios across eleven families — what each item in the working group's control list actually defends against, and where it doesn't. A vendor demo shows one path closed. This is the other fifty-eight.

How to read this

  • Prevent — the control that stops the scenario before the action runs (design-time or pre-action enforcement).
  • Detect / contain — the control that catches it during or after execution, and what limits the blast radius.
  • Cross-ref — OWASP Top 10 for Agentic Applications 2026 category (ASI01–ASI10) and the WG's four-bucket architecture: TF Trust Fabric, RP Registry/Personas, BOM Bill of Materials, RS Runtime Supervision.
  • Item numbers below use the 25-item consolidated list, not the catalog's original #1–27.

Scenarios the controls only partially close

Honest gap statements, consistent with the layer-by-layer gaps in the WG1 reference architecture. These are the scenarios where a vendor claiming full coverage should be asked to show the mechanism.

B2 · Composite authority ceilingNo token or policy framework proves a bound on the union of active grants. The combined-grant-set analysis names the problem; runtime monitoring is the only backstop, and it detects after the fact.
B4/B5 · Volume and sensitivity boundsPre-execution enforcement depends on process-notation attributes and a rights-BOM pre-action check, neither of which exists as a standard yet. Today these are caught at runtime, after exposure.
C2 · Inferred scope expansionInferred-vs-instructed action tagging is not a named control in any current agent security baseline. Every deployed guardrail assumes a payload.
F3 · Result-request mismatchLive inference results need attestation bound to the originating request. Current supply-chain signing is artifact-centric and offline.
A8/J1 · Trust maintenanceNo standard separates admission rigor from continuous re-verification, and no mandate applies the split at the cross-domain boundary where it matters most.
J3 · Consumer-delegated agentsA governance vacuum, not an engineering gap. Enterprise NHI controls do not extend to a personal agent whose identity terminates in an individual.

Status & caveat

This report renders the AOMC Threat & Risk Scenario Catalog in ONUG design language, with item names updated to the 25-item consolidated list.

  • Neither the underlying catalog nor the 25-item consolidation has been reviewed or ratified by WG1.
  • The catalog's own item numbering is stated to follow AOMC_Full_Item_Summary.md, a file not available for direct cross-check — item names here are cross-checked against the crosswalk report rather than read directly from that summary.
  • No WG1, WG2, or WG3 requirements document currently cites Signed Step Provenance, Intermediary Identity Propagation, or Inference Result Provenance.
